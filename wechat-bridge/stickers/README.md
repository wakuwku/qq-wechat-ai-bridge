# 本地表情库

不附带私人收藏或聊天图片。添加你有权使用的素材。

## 目录里会有什么

| 文件 | 是否提交 | 说明 |
|---|---|---|
| `<md5>.png` / `.gif` / `.jpg` / `.webp` | ❌ 不提交 | 表情本体，**文件名就是 md5** |
| `meta.json` | ❌ 不提交 | 桥接索引（id = md5 前 16 位、描述、标签、native 标记） |
| `native-md5.json` | ❌ 不提交 | 原生发送映射（id → md5） |
| `meta.example.json` | ✅ 提交 | 结构示例 |
| `native-md5.example.json` | ✅ 提交 | 结构示例 |
| `README.md` | ✅ 提交 | 本文件 |

## 怎么建

见 [`../tools/sticker/README.md`](../tools/sticker/README.md)：导出收藏 → 重建索引 → 校验。

## 一句话提醒

**只有图片文件不等于能发原生表情。** 微信原生表情（type47）靠 md5 在收藏列表里定位，
没有 `native-md5.json` 里的映射就只能退化成发图片。改过微信收藏之后必须重跑建库脚本，
否则会出现"每次发送先失败一次再回落发图"的静默降级。
