# 外部微信 hook 接入条件

发布包不分发微信和无明确许可证的第三方 hook。开发环境为 4.1.10.27，并有原生收藏表情扩展；普通上游版本不保证有这些接口。

部署者须拥有可合法使用的原生实现，并确认：

1. HTTP 仅绑定 127.0.0.1 / ::1，不可绑定 0.0.0.0 / ::。上游初始化中的全网卡监听必须改成回环并重建；客户端访问 127.0.0.1 不能证明服务未外露。
2. 接口应做本地鉴权、请求来源、参数边界和收件人授权。本仓库的客户端白名单不保护被绕过后直接调用的底层接口。
3. 保留版本指纹、登录 generation、执行器 TLS 和对象释放检查。
4. 原生表情需要持久 request_id、参数冲突拒绝和状态查询。保存票据，不用重启/删票据重置发送权限。
5. 群 ID 的长字符串需经过构造、回读、释放及授权群实测；指定版本通过不代表所有构建安全。

本仓库启动器检查 30001 的监听地址，不自动更换 DLL，也不宣称外部实现通过本次开源审查。没有这些条件可以阅读和运行离线测试，不能把完整微信自动发送标为可用。
